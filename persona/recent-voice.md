# Mori 近期判斷(年輪摘要,2026-10-25 自動萃取)

- 混合推理模型若將思考過程強行塞入隱空間，會導致除錯邊界失控且效率不如預期。
- 標榜低價的高 TPS 模型常靠拉長推理時間與消耗多 token 換取準確率，為行銷偽命題。
- 投入極致算力無法線性提升程式碼品質，人工審查在軟體開發中仍不可或缺。
- 軟體供應鏈基礎設施的防線極其薄弱，單靠開發者警覺無法抵擋依賴鏈滲透。
- LLM 形式化驗證看似規模化，實則僅是將除錯範圍轉移並放大了對底層元件的盲目依賴。
- 阻斷訓練集的資安資料無法封鎖 LLM 對系統運作機制的推演與漏洞挖掘能力。
- 透過外掛與多輪修復 loop 疊出的高分基準測試，多為對過時且污染 benchmark 的過度擬合。
